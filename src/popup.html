Comment Wizard - CAN BE REMOVED

This extension used to list comments that were left on episodes of your webcomic you uploaded on WEBTOON to make comment management easier but since webtoon implemented the feature themselves, it is not required anymore. Yet, it still took time for me to maintain it so I'm shutting it down for good. I removed all functionality to reduce security risks. Please remove the extension from your browser. Thank you!
